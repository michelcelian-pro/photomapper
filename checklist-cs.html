📖 Guide d'utilisation

1. À quoi sert cet outil ?

Chaque jour, une personne de l'équipe vérifie que carrelagesignature.com fonctionne correctement : pages principales, produits, panier, tunnel de commande, recherche…

Cette application sert à :

  • Suivre tous les points à vérifier, étape par étape ;
  • Signaler un bug avec une description et une capture d'écran ;
  • Envoyer un rapport complet à l'équipe (mail) ;
  • Envoyer un résumé Excel à la direction (Laurent & Pascal).

2. Faire le test quotidien

  1. Ouvre l'app (bookmark ou lien).
  2. Clique sur Démarrer en haut à droite pour lancer le chrono (facultatif).
  3. Pour chaque ligne, clique sur le lien bleu si présent, vérifie la page, puis coche OK ou Bug (voir section 3).
  4. Les catégories peuvent être pliées/dépliées (flèche à gauche). Utilise ▶ Tout plier pour une vue compacte.
  5. Une barre de progression en haut indique combien d'items tu as déjà vérifiés.

3. Marquer un test OK ou Bug

Pour chaque ligne :

  • Bouton OK (vert) — le point fonctionne.
  • Bouton Bug (rouge) — il y a un problème. Une zone de commentaire s'ouvre (voir section 4).
  • Si tu n'as pas pu vérifier un point, laisse-le sans cocher. Il apparaîtra comme "non vérifié" dans le rapport.
  • Tu peux re-cliquer pour désactiver un statut.

4. Documenter un bug (commentaire + capture)

Quand tu cliques Bug, une zone de commentaire apparaît sous la ligne.

  • Écris la description du problème en une phrase claire et professionnelle. C'est ce que ton patron va lire dans le rapport.
  • Ajoute une capture d'écran de 3 façons au choix :
    • Fais un screenshot (Cmd+Shift+4 sur Mac), puis Cmd+V dans la zone de commentaire.
    • Glisse-dépose un fichier image depuis ton bureau.
    • Clique dans la zone et sélectionne un fichier.
  • L'image s'affiche directement sous ton texte. Tu peux en ajouter plusieurs.
  • Les captures sont compressées automatiquement pour rester légères.

💡 Conseil : écris la description comme si tu parlais à ton patron. Pas de "bug" ou "KO" — plutôt "le bouton ne fonctionne pas sur mobile" ou "le prix affiché est incorrect sur la fiche produit".

5. Les notes libres

En bas de la checklist, la zone Notes libres sert à tout ce qui ne rentre pas dans un point précis :

  • Idées d'amélioration remontées par un client ;
  • Observations générales sur le site ;
  • Remarques d'un collègue (ex : Pascal propose tel changement).

Tu peux y coller des captures d'écran comme dans les commentaires de bug.

6. Les sous-catégories

Certains tests ont des sous-catégories (par exemple "Vérifier les produits en stock" a une liste de références à contrôler). Elles apparaissent avec une flèche ↳.

  • Tu coches OK ou Bug au niveau du test principal (pas au niveau des sous-éléments).
  • Si tu trouves un problème sur UNE seule sous-catégorie, coche Bug sur le test principal et précise dans le commentaire quel élément pose problème.
  • Dans le rapport final, les sous-catégories sont automatiquement listées sous leur test parent.

7. Publier le rapport & envoyer le mail à l'équipe

Une fois le test terminé, clique sur Envoyer le rapport en bas. Une fenêtre s'ouvre.

  1. Ton prénom — apparaîtra dans le rapport ("test effectué par X").
  2. Ton Gmail — le mail s'ouvrira depuis ce compte. Important si plusieurs comptes Gmail sont connectés sur le navigateur.
  3. Destinataire(s) — un ou plusieurs mails séparés par des virgules. Les contacts récents apparaissent en puces cliquables.
  4. (Optionnel) Coche Inclure aussi le test hebdomadaire si tu as rempli les deux onglets.
  5. Clique 🚀 Publier + envoyer.

Ce qui se passe ensuite :

  • Le rapport est sauvegardé en ligne (visible par tout le monde sur la page "Rapports").
  • Gmail s'ouvre dans un nouvel onglet avec destinataire + objet remplis.
  • Dans le corps du mail, colle avec Cmd+V — le rapport complet (texte + captures + lien cliquable) se met en place.
  • Clique Envoyer dans Gmail.

8. Envoyer le résumé Excel à la direction

Pour envoyer une version courte à Laurent et Pascal, utilise le bouton 📊 Résumé Excel dans la même fenêtre d'envoi.

  1. Clique sur 📊 Résumé Excel.
  2. Un fichier resume-CS-...xlsx se télécharge (visible dans la barre de téléchargement).
  3. Gmail s'ouvre automatiquement avec :
    • Destinataires : Laurent + Pascal ;
    • Objet : "test quotidien du [jour]" ;
    • Corps : message court.
  4. Glisse le fichier Excel depuis la barre de téléchargement vers la fenêtre Gmail → il se met en pièce jointe.
  5. Clique Envoyer.

Le fichier Excel contient un tableau simple : catégorie, test, statut (OK / Bug / Non vérifié), commentaire.

9. Consulter les rapports des jours précédents

Bouton 📊 Rapports en haut à droite → ouvre la page des rapports.

  • Toutes les cartes sont classées du plus récent au plus ancien.
  • Clique sur une carte pour voir le rapport complet.
  • Le bouton 🗑️ Supprimer permet de supprimer un rapport (demande confirmation).
  • Un seul rapport par jour : si tu republies, l'ancien est écrasé.

10. Problèmes courants

La checklist affiche une ancienne version.
Rafraîchis la page avec Cmd+Shift+R (force la mise à jour). La checklist est partagée automatiquement — tu dois voir "✓ Partagée" dans le header.

Gmail s'ouvre sur le mauvais compte.
Vérifie que tu as bien rempli "Ton Gmail" dans la fenêtre d'envoi. Assure-toi d'être connecté à ce compte dans le navigateur.

Le rapport n'est pas publié / erreur "failed to fetch".
Vérifie ta connexion internet. Réessaie après quelques secondes. Si ça persiste, préviens Célian.

J'ai oublié de cocher un test.
Pas de souci : un test non coché apparaît comme "non vérifié" dans le rapport. Rien n'est perdu.

Je veux modifier la checklist (ajouter un test, changer un lien).
Clique sur ✏️ Modifier en haut à droite. Les modifs sont automatiquement partagées avec toute l'équipe.

J'ai une question qui n'est pas dans ce guide.
Demande à Célian.

Fin du guide. Bon test ! 🎯
